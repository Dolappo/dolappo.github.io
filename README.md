# dolappo.github.io

Personal site of Dolapo James Falana: software & AI engineer. Plain HTML/CSS/JS served by GitHub Pages (no build step).

- `index.html`: all content
- `assets/style.css`, `assets/main.js`: styles, cursor/spotlight, hover experience list, Industry/Academic switch
- Add a photo as `assets/photo.jpg` and a CV as `assets/Dolapo_Falana_CV.pdf`, then uncomment the links in `index.html`.

Tip: link `https://dolappo.github.io/?mode=academic` in academic applications to open the site in Academic view.
