Lead, Design · Frontend & Mobile · Fintech

NadaPay: checkout, embedded wallets and mobile security

At NadaPay I lead design and own frontend and mobile. I built and shipped the payment checkout end to end: an iframe checkout in React/TypeScript, a drop-in inline JS SDK that merchants add with one script tag, and standalone payment and invoice pages, served from S3 and CloudFront. I made the architecture calls behind it: the wallet is the main conversion path, the flow never needs to know which blockchain is underneath, and test or live mode comes from the merchant's API key.

I also designed the StableCash Flutter SDK, a multi-tenant plugin that lets other apps offer USDC and cNGN wallets and Visa cards, branded and configured from a dashboard. It is hardened with certificate pinning, secure storage and quote-bound action tokens, and I replaced simple root detection with Play Integrity attestation in a 14-step security pipeline. Next is a claim-link flow so people can send money to phone numbers that aren't registered yet.

4 worldscode · design · words · AI

Founder · Edtech · Game

Codie's World: learn to code and design through games

I founded Codie's World and built it: one web game for kids aged 6 and up, with a robot guide, Codie, who explains why things happen. In Brick Bot, kids don't just play a brick-breaker, they build it: they snap code blocks together to tell a robot where to put the bricks, press Run, then play the game they made. Seven worlds teach sequence, loops, variables, if, events, functions and sorting algorithms. Older kids type real code in Pseudocode, Python, JavaScript or Java. There are also sections for design principles, English and a Data Lab where kids train a robot and learn about bias.

It works offline as an installable web app, with no accounts, ads or purchases. Codie's voice is pre-recorded with an open-source voice model, so nothing is sent to a server, and automated tests check that every level can be solved for 3 stars.
